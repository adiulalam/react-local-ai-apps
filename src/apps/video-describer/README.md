# Video Describer

Real-time visual scene narration and audio description powered by local AI.

## Features

- **Local Vision Model:** Scene captioning powered by `Xenova/vit-gpt2-image-captioning`.
- **Text-to-Speech Narration:** In-browser audio narration using speech synthesis.
- **Multiple Inputs:** Supports uploaded video files, sample media, and live webcam feeds.
- **Auto-Narrate Mode:** Periodically captures and narrates scenes while the video plays.
